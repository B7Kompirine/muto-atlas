# Notice on data

The [MIT license](LICENSE) covers the code in this repository only.

No GTA V game data is distributed with this plugin. The heavy data layers
(archetypes, world entities, animation clips, skeletons, ...) are generated
locally from the user's own, legally obtained GTA V installation using
CodeWalker, and are excluded from version control (see `.gitignore`).

The light data layers are generated at install time from
[DurtyFree/gta-v-data-dumps](https://github.com/DurtyFree/gta-v-data-dumps)
and from the user's own FiveM server resources. They are likewise not
redistributed here.

GTA V and its assets are property of Rockstar Games. This project is not
affiliated with or endorsed by Rockstar Games, Take-Two Interactive, or the
Cfx.re / FiveM project.
