# Code of conduct

**English** · [Türkçe](docs/CODE_OF_CONDUCT.tr.md)

This project is a place to share measurements and fix mistakes, including the
maintainer's. That only works if people can be wrong in public without being
attacked for it.

- **Criticise the claim, not the person.** "This number doesn't reproduce on my
  build — here is my output" is welcome. Insults are not.
- **No harassment, discrimination or personal attacks**, in any language,
  anywhere in this repository.
- **No leaked or pirated content.** No links to leaked resources, escrow
  bypasses or cracked tools.
- **Assume good faith**, and if you were wrong, say so. Everyone here has been.

The maintainer may edit, hide or remove comments, issues and pull requests that
break these rules, and may block repeat offenders. To report something, use
GitHub's **Report content** option on the comment, or contact
[@B7Kompirine](https://github.com/B7Kompirine).
